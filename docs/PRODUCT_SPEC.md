# Heart Studio 产品规格（当前确认方向）

## 产品定位
Heart Studio 是免费、免注册的公开工具网站。平台不向创作者或体验者收费，不代收款、不抽佣、不建立平台支付订单。它帮助一位创作者制作一段逐关展开的互动心意体验，并通过链接分享给另一位体验者。

## 角色与流程

### 创作者（女方）
1. 打开网站，无需注册或登录。
2. 创建一份心意体验，设置作品标题、昵称/头像、开场文字与主题。
3. 添加多个独立关卡；每关可设置标题、进入前提示、私密文字，以及照片、语音或视频素材。
4. 每关可单独填写金额提示，并上传/填写自己收款账户对应的微信或支付宝收款码。
5. 预览男方实际看到的页面，生成专属分享链接并发送给体验者。

### 体验者（男方）
1. 点击分享链接，无需注册、登录或下载应用。
2. 在手机端以逐屏交互方式体验邀请、开场内容与各关内容。
3. 每关单独展示创作者设置的金额提示；如创作者提供收款码，体验者可自行决定是否通过微信/支付宝向创作者付款。
4. 付款发生在用户自己的支付应用与创作者收款账户之间。网站不发起、不确认、不验证付款；体验者可自行选择继续体验或离开。
5. 完成体验后显示“体验结束”，不显示平台订单完成或支付成功。

## 交互与视觉标准
- 延续已确认的温柔甜美粉色视觉风格、圆润卡片、柔和阴影、悬浮元素和细腻转场。
- 创作者端与体验者端均以手机视口为主，避免整页上下滚动。
- 通过点击/轻触逐屏推进；长内容拆分成独立屏幕或弹窗，不以页面滚动承载流程。
- 关卡内容、媒体和收款码均在独立卡片/弹窗中展示；关闭弹窗后返回原步骤。
- 每个步骤有明确的返回、继续和结束操作；不得以误触或默认勾选替代用户选择。
- 分享链接打开后的体验者端，必须与创作者预览尽可能一致。

## 数据与隐私边界
- 网站不要求注册账号。
- 为使跨设备分享链接可用，作品内容需要在服务端临时保存；不能同时承诺“完全不存储任何数据”。
- 推荐采用不可猜测的随机分享令牌；分享内容默认在发布后 7 天过期，创作者可提前删除；体验结束后应按明确规则及时清理。具体期限需在实现和隐私说明中保持一致。
- 不公开列出作品，不提供通过昵称/手机号搜索他人作品的入口。
- 分享链接相当于访问凭证，界面应提醒创作者仅发送给预期对象。
- 上传媒体仅接受允许的图片/音频/视频格式并限制大小；拒绝脚本、可执行文件和不安全远程资源。
- 不采集不必要的身份、通讯录、定位或支付凭据；收款码由创作者主动提供，网站不读取支付应用内信息。

## 明确不做
- 不做平台注册登录、会员、软件授权码或软件销售。
- 不接入平台支付、不创建平台订单、不提供支付成功校验、不代收、不分账、不抽佣。
- 不抓取或盗用抖音等第三方平台的个人照片；媒体由创作者自行上传或提供合法使用的素材。
- 不声称网站验证了线下/站外转账，也不把体验者点击“我已付款”当成支付事实。

## 当前实现状态（必须如实维护）
本规格是目标产品方向，不代表所有功能已经实现。当前仓库仍包含账户认证、创作者登录、数据库订单/支付预留和传统网页式体验流程；这些现存实现与本规格存在差异，必须逐项迁移、删除或隔离后，才能称为符合当前产品方向。任何上线、支付或数据保留能力都必须以实际代码、测试和部署验证为准。
