# 产品规格

## 角色
- 软件管理员：签发一次性软件授权码、管理软件销售。
- 创作者：激活软件、创建作品、编辑关卡、分享链接、配置合规收款渠道。
- 体验者：通过专属分享链接访问作品、逐关体验、查看惊喜内容并留下回应。

## 规则
- 创作者只能管理自己的作品和订单。
- 关卡金额为可选的心意参考信息；当前互动体验不依赖付款。
- 公开接口只返回标题、提示、心意金额参考等预览字段；私密惊喜内容由体验者会话通过专属分享链接打开。
- 已发布作品的有效关卡可直接体验；未来如增加付费解锁，付款成功必须由服务端验证支付机构签名/查询结果，绝不信任浏览器传入的 paid 标记。
- 订单绑定 creator、experience、level、amount、currency、provider、provider_transaction_id。
- 支付回调幂等；退款保留审计记录并按规则撤销访问权限。
- 关卡交易资金走支付机构批准的商户/平台结算模式；软件销售款与创作者交易款分离。

## MVP
登录注册、创作者授权、多作品管理、关卡编辑、分享页、私密内容读取、订单后台、支付沙盒。

## 暂不开放
商户准入完成前的真实付款；伪造支付成功；未经授权抓取第三方个人照片。
