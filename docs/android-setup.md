# 小美 AI 安卓版安装与隐私说明

当前测试构建：**0.9.2（versionCode 11）**。这是用于设备测试的 debug APK，不是 Google Play 或其他应用商店的正式发行包。

## 安装

1. 将 APK 下载到 Android 手机。
2. 在系统提示时，允许当前浏览器或文件管理器安装此来源的应用。
3. 安装并打开小美 AI。
4. 如果设备已安装旧版 0.9.1（versionCode 10），0.9.2 的版本代码更高，可以作为更新安装。

请只在自己信任的设备上安装测试包。Android 可能显示“来自未知来源”的安全提示，这是侧载 APK 的系统保护提示。

## 主要功能

- 手动输入或粘贴公开评论文本，按需求和意向生成分析结果与私信草稿。
- 打开抖音关键词搜索页面，手动浏览评论。
- 可选的屏幕文字辅助：默认关闭，用户主动开启并在 Android 系统辅助功能设置中授权后，读取当前前台页面的可访问文字。
- 甜美风格悬浮聊天建议面板和本地关系沟通知识库。

## 可选屏幕文字辅助的启用方式

1. 在小美 AI 内打开“启用屏幕文字读取（默认关闭）”。
2. 点击“前往系统辅助功能设置”，在 Android 设置中找到小美 AI 辅助功能服务并主动启用。
3. 返回抖音并打开你希望分析的评论页面。
4. 回到小美 AI，点击“读取当前页面可见评论文字”，先检查读取结果。
5. 只有在你主动点击 AI 分析后，文本才会发送给你自己配置的 AI 服务商；应用不会自动发送私信。

屏幕辅助是 Android 的高权限能力：启用后，系统可能允许服务读取当前前台应用的可访问文字。代码会跳过标记为密码的控件；读取内容先保存在本机，不会因为打开辅助功能就自动发送给 AI。

## 本机缓存与隐私

- 屏幕文字读取默认关闭。
- 关闭应用内的屏幕文字开关时，会清除已读取的屏幕文字缓存。
- 手动点击“清除已读取的屏幕文字”也会立即清除本机缓存。
- Android 停止辅助功能服务时，会清除本机屏幕文字缓存。
- 读取的是应用界面提供的可访问文字，不是屏幕截图。
- 请勿在银行、支付、密码、医疗或其他高度私密页面开启屏幕辅助；只读取你有权查看和处理的内容。
- 不要收集、分析或联系明确拒绝联系的人；生成的私信只是草稿，需要你自行审核和发送。

## 悬浮窗

如需使用悬浮聊天建议面板，按应用提示在 Android 系统设置中授予“小美 AI 显示在其他应用上层”的权限。不需要时可关闭悬浮窗权限或长按关闭悬浮按钮。

## 测试版限制

- 需要用户自行配置并承担 AI 服务商的 API 使用费用；APK 不内置你的个人 API Key。
- 当前不是正式商店签名发行版，尚未完成不同品牌手机的兼容性与完整安全测试。
- 屏幕辅助是否能读取某个应用，取决于该应用是否向 Android 暴露可访问文字。
- AI 分析结果可能不准确；请先审核，不要把自动生成内容当作事实。
