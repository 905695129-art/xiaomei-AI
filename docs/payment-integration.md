# 正式支付接入清单（实施前置条件）

本文是工程接入边界，不代表当前已经开通微信支付或支付宝。当前 `POST /api/orders` 必须继续 fail closed，直到商户准入、服务端支付、回调验签、退款及结算测试全部完成。

## 目标资金流

- 体验者为某个作品的某一关付款。
- 收款主体应为该作品创作者本人/其依法登记的经营主体，而不是 Heart Studio 代收。
- Heart Studio 不从关卡交易中抽取平台佣金。
- 支付机构仍可能收取支付手续费；创作者仍需自行承担适用的税务、退款和消费者保护义务。“平台不抽佣”不等于“交易零成本”。
- 每个创作者必须完成支付机构要求的实名认证、商户审核和收款账户绑定。不得把个人收款二维码当成可验证的自动化支付回调。

## 商户方案必须先确认

接入前必须由支付机构或其正式服务商书面确认：
1. 是否允许平台型产品为多个独立创作者提供收款能力。
2. 是否支持服务商/平台与子商户模式，以及每位创作者独立进件。
3. 资金是否能直接结算到对应子商户的已审核账户。
4. 平台是否承担交易信息展示、订单协助、投诉、退款或其他平台责任。
5. 支付手续费由谁承担，结算周期、限额、冻结和风控规则是什么。
6. 创作者所在国家/地区、经营类别及商品内容是否符合支付机构准入政策。

不能只凭“API 能创建付款码”就认定这种业务结构合规。

## 服务端下单契约

客户端只提交作品 slug 和关卡 ID，不得提交可信的价格、创作者 ID、buyer_ref 或支付状态。服务端必须：
- 从 HttpOnly 买家会话识别 buyer_ref。
- 从数据库读取作品、创作者、币种、关卡和当前价格。
- 确认作品已发布、关卡有效、价格大于零。
- 读取该创作者已审核的子商户/收款配置。
- 服务端创建本地 pending 订单，再向支付机构发起预下单。
- 将支付机构订单号绑定到本地订单；不得允许客户端自行指定金额或收款主体。
- 返回由支付机构生成的支付参数/跳转地址；不得在前端模拟成功。

目前数据库已经有新订单校验触发器、订单商业身份不可变约束、购买快照和每位买家每关唯一有效订单约束。支付 API 仍关闭。

## 异步回调契约

正式回调处理器必须按支付机构正式文档实现，不能用通用 HMAC 示例替代真实验签：
1. 读取原始请求体，按机构要求验证签名、证书/公钥、时间戳、随机数和必要的解密字段。
2. 校验回调对应的商户/子商户身份和应用配置。
3. 校验事件 ID、事件类型、订单号、支付状态、金额和币种。
4. 使用 `payment_provider_events` 唯一键去重，并记录 payload SHA-256；不要把支付密钥或敏感支付数据写入日志。
5. 在数据库事务中锁定事件和订单。
6. 仅允许真实支付成功事件调用 `heart_finalize_verified_payment`，一次性将订单置为 paid、发放 entitlement 并标记事件 processed。
7. 重复通知必须幂等；金额不符、商户不符、订单不符、签名失败均拒绝。
8. 对临时处理失败采用受控重试和告警，不能将未验证事件标为 paid。

数据库函数 `heart_finalize_verified_payment` 只负责验签之后的原子落库，不验证支付机构签名。其 PUBLIC 执行权限已撤销。生产部署时必须使用最小权限数据库角色，只向可信回调服务授予必要执行权限；不要把数据库 owner 凭据放进 Web 运行时。

## 退款契约

- 退款只能由有权限的服务端发起，不能由浏览器直接改订单状态。
- MVP 当前只支持整笔退款，退款金额和币种必须与原订单一致。
- 每次退款必须有唯一幂等键，并记录支付机构退款单号。
- 只有收到并验证支付机构的退款成功结果，才把退款记录改为 succeeded。
- 成功退款触发订单变为 refunded；已有 entitlement 不应再通过付费访问校验。
- 失败、取消、处理中状态不能被伪装成退款成功。
- 退款 API/回调执行器尚未实现，数据库约束不等于已经能退款。

## 上线前验收

- [ ] 支付机构书面确认平台/子商户模式及业务类别可准入。
- [ ] 每位创作者完成实名、商户审核及结算账户绑定。
- [ ] 测试环境验证下单、取消、超时、重复回调、乱序回调、金额不符和币种不符。
- [ ] 验证签名失败、证书轮换、回调重放及异常告警。
- [ ] 验证成功退款、重复退款、退款失败和退款后访问撤销。
- [ ] 验证创作者只能查看自己的订单，不能读取其他创作者收款配置。
- [ ] 核对账单、手续费、结算金额和创作者对账导出。
- [ ] 完成隐私政策、服务条款、退款规则、投诉处理和数据保留策略。
- [ ] 完成生产数据库备份、迁移演练、密钥轮换及恢复演练。

在以上项目完成并通过真实商户沙箱验收之前，产品页面必须继续明确提示“暂未开通真实支付”，不得向体验者收取真实款项。
