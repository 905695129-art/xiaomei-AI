# 中国大陆部署与可用性验收清单

> 本文是部署实施清单，不构成法律意见或合规认证。目标是将 Heart Studio 部署到中国大陆可正常访问的自有域名和云资源上。仅把代码放在 GitHub、海外托管平台或海外对象存储，不能证明中国大陆可用。

## 1. 部署目标架构

建议生产拓扑：

- Web：支持 Next.js Node.js 运行时的中国大陆云主机/容器服务，区域选择大陆境内可用区。
- 数据库：同区域 PostgreSQL 托管实例或受控自建 PostgreSQL；仅私网访问。
- 图片：同区域对象存储，绑定自有备案域名/CDN 域名；桶私有，上传走签名表单。
- 网络：自有域名 + HTTPS；反向代理/负载均衡；数据库和对象存储不暴露管理端口。
- 运维：异地/跨可用区备份策略、监控告警、访问日志、错误追踪、密钥轮换和恢复演练。

部署商和具体产品由运营主体按资质、区域、数据处理要求及预算选定；不要把海外预览地址作为大陆生产入口。

## 2. 域名、备案与运营前置核验

上线前由实际运营主体向云服务商和专业法律顾问核实：

1. 域名实名、DNS、TLS 证书和 ICP 备案要求；网站备案信息必须与真实运营主体及接入服务匹配。
2. 是否涉及增值电信业务许可、公安联网备案、算法/生成式 AI 或其他专项要求。不要把 ICP 备案等同于经营许可。
3. 《个人信息保护法》《数据安全法》《网络安全法》及适用的未成年人保护、内容治理、投诉举报和个人信息权利响应要求。
4. 用户上传照片、封面、二维码、互动文字和关系信息的收集目的、最小化范围、保存期限、访问权限、删除/导出流程。
5. 运营主体、客服/投诉渠道、隐私政策和服务条款必须填入真实信息并经过审查，当前仓库中的政策页面仍是草案。

在这些核验完成前，不应公开宣称已完成大陆合规。

## 3. 必须配置的环境变量

| 变量 | 生产要求 |
| --- | --- |
| `APP_URL` | 设置为最终 HTTPS 公网域名，例如 `https://你的正式域名`；用于分享链接和 Open Graph 元数据。 |
| `DATABASE_URL` | 指向大陆部署区域的 PostgreSQL 私网地址；启用 TLS/强认证，限制网络来源。 |
| `POSTGRES_PASSWORD` | 强随机密码；使用云密钥管理，不提交仓库、不写入镜像。 |
| `STORAGE_ENDPOINT` | 大陆区域对象存储 S3 兼容 API endpoint。 |
| `STORAGE_PUBLIC_URL` | 自有备案域名下的图片访问地址，必须验证 CDN 回源、HTTPS 和防盗链策略。 |
| `STORAGE_REGION` / `STORAGE_BUCKET` | 按云厂商实际区域和桶名设置。 |
| `STORAGE_ACCESS_KEY` / `STORAGE_SECRET_KEY` | 最小权限专用身份，定期轮换，不能使用主账号密钥。 |
| `PAYMENT_PROVIDER` | 当前保持 `disabled`。静态二维码自助确认不是平台支付，也不能核验到账。 |
| `EMAIL_PROVIDER` | 当前保持 `disabled`，直到完成大陆邮件服务商接入、域名验证、退信/投诉处理及邮件链路测试。 |
| `EMAIL_FROM` | 使用已验证的自有域名发件地址。 |
| `REQUIRE_VERIFIED_EMAIL` | 只有邮件验证全链路在生产验收通过后才启用。 |

不得把 Resend 或其他海外服务默认当作大陆生产邮件方案。当前代码尚未提供大陆邮件/短信服务商适配器；在实现和测试完成前，账户验证、找回密码等邮件能力不能视为可用。

## 4. 发布流程

1. 从已通过 CI 的明确 Git commit 构建不可变 Docker 镜像，记录镜像 digest。
2. 先在同区域预发布环境执行数据库迁移；备份数据库并验证回滚/恢复步骤。
3. 配置生产环境变量与密钥，确保支付仍关闭；部署应用容器。
4. 配置域名解析、HTTPS、反向代理健康检查、请求体大小限制、限流和安全响应头。
5. 配置对象存储 CORS、签名上传、图片域名 HTTPS、生命周期和孤儿对象清理。
6. 运行健康检查、数据库读写、图片上传/读取、创作者注册/登录、作品发布、分享访问、逐关解锁、免费关卡和回应收件箱 E2E。
7. 在中国大陆不同运营商网络、Android/iOS 微信内置浏览器、微信外置浏览器和常用手机浏览器上实测。
8. 检查微信分享卡片的标题、描述、封面和链接；如需微信 JS-SDK 分享能力，另行完成公众号/开放平台配置、域名校验及签名服务，不能仅依赖浏览器 Web Share API。
9. 检查备份恢复、告警、日志脱敏、账号注销/数据导出、隐私请求响应和安全事件流程。
10. 完成运营主体和法律审核后，才对外发布生产域名。

## 5. 当前明确未完成的大陆上线事项

- 尚未选定或开通大陆云厂商、区域、生产主机/容器、PostgreSQL、对象存储、CDN 和正式域名。
- 尚无生产 `APP_URL`、密钥、数据库凭据和对象存储凭据。
- 尚未完成 ICP/许可适用性核验、备案和运营主体法律审查。
- 尚无大陆邮件/短信适配器；邮件默认关闭。
- 尚无恶意文件/内容扫描服务、对象存储孤儿文件自动清理和正式灾备演练。
- 尚未完成真实大陆网络、微信内置浏览器和多运营商设备验收。
- 平台支付保持关闭；无支付机构商户接入、签名回调、退款、对账或结算。
- GitHub CI 通过只代表自动化构建和测试通过，不等于大陆生产部署或合规验收。

## 6. 发布验收标准

只有同时满足以下条件，才能标记为“大陆正式上线”：

- 正式域名从中国大陆多个运营商网络可稳定访问，HTTPS 证书有效。
- 应用、数据库、对象存储/CDN 的数据流向和部署区域已核验并符合运营要求。
- 备案/许可及运营主体审核已完成（如适用）。
- 注册、登录、作品编辑、上传、发布、微信分享、逐关体验、免费关卡、回应、导出和注销链路均通过真实环境验收。
- 隐私政策、服务条款、投诉渠道、数据保留和安全响应流程正式生效。
- 备份恢复、监控告警、日志脱敏和安全扫描已验收。
- 未上线的支付能力保持关闭，产品页面不暗示平台担保或到账核验。
