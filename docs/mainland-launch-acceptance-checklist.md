# Heart Studio 中国大陆上线验收清单

> 状态：上线前工作底稿。此清单不是法律意见、备案证明、支付机构批准或安全认证。任何未完成的强制门槛都意味着不得向公众开放收费生产服务。

## 0. 当前边界

- [ ] 选定并核实实际运营主体、注册地址、负责人和用户投诉联系人。
- [ ] 明确产品运营模式：仅提供情侣互动工具，还是代收款、撮合交易、内容付费或向创作者分账。不同模式可能触发不同监管和支付要求。
- [ ] 在运营主体、业务模式和服务范围未完成法律审查前，不启用面向公众的收费生产功能。
- [ ] 不把静态个人收款码的“用户自助确认”描述成平台支付、平台验款、担保交易或资金托管。

## 1. 域名、云资源与备案

- [ ] 购买或准备由运营主体合法控制的大陆域名，完成实名核验。
- [ ] 选择中国大陆地域的云主机、关系数据库、对象存储、CDN、日志与备份服务。
- [ ] 核实每个服务的数据实际存储地域、备份地域、运维访问地和子处理方。
- [ ] 由云服务商和主管部门确认 ICP 备案、公安联网备案、增值电信业务许可等具体适用性；不能把 ICP 备案当成经营许可。
- [ ] 配置 HTTPS、HSTS、安全响应头、域名证书自动续期、DNS 变更保护。
- [ ] 生产数据库与对象存储不得公开管理端口；密钥只通过受控密钥管理或部署密文注入。
- [ ] 完成异地/同城备份策略、恢复演练和 RPO/RTO 记录。

## 2. 个人信息与内容治理

- [ ] 由中国大陆法律顾问审查《隐私政策》《用户协议》《儿童个人信息保护规则》及实际数据处理流程。
- [ ] 明确收集字段、处理目的、合法性基础、保存期限、访问权限、删除机制和第三方接收方。
- [ ] 私密消息、情侣关系信息、头像和照片按高风险个人信息场景进行最小化处理；默认不公开、不用于训练或广告。
- [ ] 明确照片上传、AI 图像处理、内容存储、分享链接和撤回/删除的用户控制。
- [ ] 建立用户投诉、举报、侵权通知、内容下架、账号封禁、证据留存和申诉流程。
- [ ] 建立未成年人保护措施；确认年龄策略、疑似未成年人处置、禁止不适宜内容及必要的监护人机制。
- [ ] 对上传图片实施格式解码、大小/像素限制、恶意文件检测、滥用速率限制和孤儿对象清理。
- [ ] 对公开文案和用户提交内容配置适当的审核、举报与人工复核机制。

## 3. 支付与商业模式

- [ ] 由法律顾问和支付机构确认当前“创作者个人静态收款码 + 买家自助确认”的模式是否适用于拟开展的收费数字服务。
- [ ] 在未获得适用批准前，不宣称平台验证付款，不代收、不归集、不托管或擅自分配资金。
- [ ] 若接入微信支付/支付宝，完成商户主体审核、产品场景报备、支付产品开通和必要的服务商/子商户授权。
- [ ] 服务端验证支付签名、商户号、应用号、金额、币种、订单号、交易状态与回调时间；绝不信任前端“支付成功”参数。
- [ ] 支付回调必须验签、幂等、可重放保护；退款、撤销、关单、争议和对账均有可审计记录。
- [ ] 明确平台与创作者之间的合同关系、开票/税务责任、退款责任和消费者告知。
- [ ] 通过沙箱和小额真实交易验收后，才逐步开放生产流量。

## 4. 微信与移动端体验

- [ ] 在微信 iOS、微信 Android、系统浏览器、主流 Android 浏览器和 iOS Safari 实机验收。
- [ ] 验收微信内分享、右上角分享提示、复制链接、链接预览卡片和返回路径。
- [ ] 若使用微信 JS-SDK，完成公众号/开放平台主体配置、域名校验、签名服务和安全域名配置。
- [ ] 验收二维码长按识别、扫码返回、键盘遮挡、刘海屏安全区、弱网、重复点击和页面刷新恢复。
- [ ] 所有关键按钮有加载、成功、失败、重试和防重复提交状态；动画尊重减少动态效果设置。

## 5. 账号、权限与安全

- [ ] 对创作者登录、密码重置、邮箱/手机验证和会话撤销进行安全测试。
- [ ] 验证所有创作者 API 的对象归属与越权访问防护。
- [ ] 验证访客进度、解锁记录和回应内容严格按访客身份隔离。
- [ ] 完成依赖漏洞扫描、静态分析、动态测试、渗透测试和安全问题修复。
- [ ] 配置 WAF/限流、异常登录告警、上传滥用告警、数据库审计与密钥轮换。
- [ ] 进行多实例并发、故障切换、数据库连接池和对象存储压力测试。

## 6. 生产验收与发布

- [ ] CI 在待发布提交上全部通过，且测试覆盖迁移、逐关解锁、访客隔离、上传和生产容器。
- [ ] 在与生产同构的预发布环境完成端到端验收。
- [ ] 运营、客服、投诉处理、退款和安全事件值班流程已演练。
- [ ] 监控健康检查、错误率、延迟、支付对账、存储容量和备份状态。
- [ ] 发布采用灰度、可回滚数据库迁移和明确回滚负责人。
- [ ] 记录上线批准人、版本号、配置快照、备案/许可材料和验收报告。

## 7. 上线决策

只有在以下条件全部满足后，才可把项目状态改为“可在中国大陆公开运营”：

1. 运营主体与业务模式经过审查；
2. 适用备案、许可及平台审核完成；
3. 数据处理与用户协议完成法律审查；
4. 正式支付模式获支付机构确认并通过验收，或明确采用经审查的非平台支付模式；
5. 境内生产基础设施、监控、备份和恢复演练完成；
6. 安全、内容治理、未成年人保护与客服投诉流程可运行；
7. 实机验收和生产发布审批完成。

**当前项目仍处于工程开发/预发布准备阶段。** GitHub Pages 是静态预览，不是大陆生产服务；未配置真实域名、云资源、运营主体和商户凭证前，不得宣称已经正式上线。
