# Heart Studio｜免费免注册心意互动工具

Heart Studio 的目标版本是一个面向中国大陆用户的免费工具网站：女生无需注册或登录即可制作心意邀请和逐关体验，生成分享链接；男生无需注册或下载即可打开体验。

## 已确认的产品规则

- 网站对创作者和体验者免费，不收会员费、制作费或平台手续费。
- 不设置注册、登录、账户、充值、平台订单或平台支付。
- 女生可为每一关设置标题、提示、金额展示、文字/图片/语音/视频内容，以及自行提供的微信或支付宝收款二维码。
- 男生通过分享链接逐关体验；每关可展示女生设定的金额与二维码。
- 付款完全由双方在微信/支付宝等外部渠道自行完成。网站不代收、不验证付款、不分账，扫码付款不会自动解锁关卡。
- 作品仅短期暂存，不做永久用户档案。由于分享链接需要跨设备访问，体验内容必须在有效期内暂存；默认建议未完成 7 天过期、完成后 24 小时清理，并支持女生主动删除（有效期策略待最终确认）。

## 当前仓库状态

**当前 main 分支仍是旧的账户/订单型应用，不等于上述免费免注册版本。** 旧代码包含邮箱账户、创作者登录、买家会话、订单/购买记录和支付预留模块，需要进行架构级重构，不能仅隐藏界面按钮。

新的重构工作在 free-anonymous-experience 分支开始。产品与技术决策见 docs/free-anonymous-architecture.md。

## 中国大陆部署说明

GitHub Pages 只能用于静态界面预览，无法单独承载跨设备分享所需的临时数据 API 和私有媒体存储。正式面向中国大陆公开服务，需要运营主体准备域名、境内云资源、ICP备案、数据库、对象存储、HTTPS 和自动清理任务。免费运营不代表免除备案、隐私保护或内容治理义务。

在代码重构、生产环境部署和大陆网络验收完成前，不应宣称网站已经正式上线或保证大陆可访问。

## 开发方向

1. 将创作流程改为匿名创建与本机管理密钥。
2. 建立带随机分享令牌的短期体验包 API。
3. 实现私有媒体上传、访问和自动删除。
4. 重构男方免登录逐关体验与外部二维码展示。
5. 移除旧账户、订单、买家会话和支付功能。
6. 完成构建、端到端测试，再部署至中国大陆合规环境。
