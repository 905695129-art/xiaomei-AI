# 心意闯关 · Heart Studio

Heart Studio 是一款独立的情侣互动闯关 Web 应用。它不是聊天助手，也不包含小美 AI 的悬浮聊天窗或六种对话模式。产品围绕「创作者设计心意关卡 → 分享专属链接 → 伴侣逐关体验 → 留下回应 → 创作者查看回应」展开。

## 产品体验

### 创作者
- 注册、登录并创建自己的心意体验。
- 上传自定义封面，设置作品标题、描述和主题。
- 创建、编辑、排序和删除关卡；每关独立设置标题、进入提示、私密内容和价格。
- 支持 0 元免费关卡；免费关卡仍遵循前序关卡完成后才能进入的顺序规则。
- 上传、预览和移除自己的收款二维码。
- 发布后复制专属分享链接。
- 在回应收件箱查看体验者留下的回应，并管理已读状态。

### 体验者
- 通过创作者分享的专属链接进入作品。
- 查看关卡标题、预览提示和每关价格。
- 按顺序体验关卡；不能通过直接访问 URL 跳过前序关卡。
- 免费关卡无需付款，完成互动后继续推进。
- 付费关卡展示创作者上传的静态收款二维码。体验者自行与创作者完成约定转账后，可点击「我已按约定完成转账，继续解锁」继续体验。
- 体验者不需要上传付款截图，也不需要等待创作者手动确认。
- 可在已解锁关卡中提交心意回应；回应会进入创作者收件箱。

## 付款边界（重要）

当前二维码流程是双方自行完成转账后的**自助确认机制**，不是平台支付：
- 平台不会核验银行或支付账户是否到账。
- 平台不会托管资金、代收款或向创作者结算。
- 自助确认记录明确标记为 `self_attested_transfer`，不会伪装成平台已验证的 `paid` 订单。
- 免费关卡不生成订单或付款解锁台账。
- 如果需要平台验证支付、退款或结算，必须另行接入获准支付机构的商户服务、服务端签名验证、异步回调、对账与退款流程。在完成这些工作前，不得宣传平台担保支付。

## 路由概览

- `/creator`：创作者注册、登录、作品列表和管理。
- `/creator/[experienceId]`：作品和关卡编辑器、封面及收款码管理、发布。
- `/creator/responses`：互动回应收件箱。
- `/creator/orders`：订单记录页面；当前二维码自助确认不生成平台订单。
- `/p/[slug]`：情侣体验分享页。
- `/purchases`：体验者购买记录页面；当前自助确认不等同于平台付款订单。
- `/privacy`、`/terms`：隐私政策与服务条款草案，尚待补齐运营主体信息并进行法律审查。

## 安全与数据规则

- 创作者接口校验会话和作品归属；公开 API 只返回已发布作品的公开元数据。
- 体验者进度使用 HttpOnly 会话 cookie 隔离，不接受客户端指定访客身份。
- 私密关卡内容在服务端检查顺序、解锁状态后才返回。
- 关卡回应需要验证体验者会话及该关卡的可访问状态。
- 图片上传校验文件类型并进行真实解码、像素限制和格式规范化；这不等于恶意软件扫描。
- 邮件 provider 默认关闭；只有显式选择并配置受支持服务时才启用。未配置时邮件功能应 fail closed。
- 支持创作者会话管理、密码修改、账户恢复、数据导出和账户注销；邮件验证/重置需要真实邮件服务配置。
- 页面动画尊重 `prefers-reduced-motion`。

## 本地开发与容器运行

需要 Node.js 22+、PostgreSQL 以及按需配置的 S3 兼容对象存储。

```bash
npm install
cp .env.example .env.local
# 在 .env.local 配置数据库、会话及所需的对象存储参数
npm run db:migrate
npm run dev
```

也可使用仓库提供的 `Dockerfile` 和 `docker-compose.yml`。CI 会验证数据库迁移、类型检查、图片处理、邮件 fail-closed、动画覆盖、Next.js 生产构建、Docker 生产容器和 HTTP 端到端流程。

## 当前交付状态

此仓库包含 Heart Studio 的应用代码和生产准备工作，但**代码仓库或静态预览不等于正式上线**。部署到真实生产环境前仍需：
1. 确定运营主体、域名和部署区域；如面向中国大陆运营，核实云资源、ICP备案/许可及相关法律要求。
2. 配置生产数据库、对象存储、备份、监控、日志和恶意内容扫描。
3. 配置真实邮件/短信供应商并完成账户恢复链路验收。
4. 完成隐私政策、服务条款、数据处理流程和未成年人保护等审查。
5. 若启用平台支付，完成支付机构商户准入、服务端签名验证、回调、退款、对账及结算验收。
6. 完成压力测试、灾备恢复测试和真实设备/微信内置浏览器验收。

不得将当前版本描述为已开通平台支付、已核验二维码转账或已完成中国大陆生产合规。
